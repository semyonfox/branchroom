# Reporting security issues

Report a vulnerability in Branchroom privately through a [GitHub security advisory](https://github.com/semyonfox/branchroom/security/advisories/new). Do not open a public issue.

Only the `main` branch gets fixes. Say which commit you tested, which settings differ from the defaults, and how to reproduce it from a fresh install.

If the issue also reproduces on unmodified Gitea, report it to Gitea too, following [their security policy](https://github.com/go-gitea/gitea/security/policy). Branchroom picks up their fix when it merges upstream.
