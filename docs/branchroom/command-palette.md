# Command palette

Press Ctrl+K or Cmd+K, or click **Search or jump to** in the top bar. The `/` shortcut still focuses that box.

Start typing to find repositories, files in the current repository, issues and pull requests. Recent pages stay in your browser. The palette also offers commands for the current page.

Use the arrow keys to choose a result, Tab or Shift+Tab to move between sections, Enter to open it and Escape to close.
